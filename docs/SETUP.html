📸 Étape 2: Ajouter ta photo

IMPORTANT: C'est l'étape clé pour voir le site prendre vie.

  1. Prépare une photo de toi au format JPG ou PNG
  2. Dimensions recommandées: 450 x 600 pixels (ratio 3:4)
  3. Compresse l'image (< 200 KB): https://tinyjpg.com
  4. Place le fichier à: assets/images/photo.jpg
# Créer le dossier si absent mkdir -p assets/images # Placer ta photo: assets/images/photo.jpg
✓ Le site charge automatiquement la photo. S'il manque un fallback SVG s'affiche.

🌐 Étape 3: Tester en local

Ouvre le site dans ton navigateur pour le prévisualiser.

  1. Double-clique sur index.html
  2. Ou ouvre via le navigateur: File → Open
  3. Ou en ligne de commande: cd vers le dossier et ouvre index.html
⚠️ Pour les ressources dynamiques (accordéons, thème), utilise un serveur local:
# Python 3 python -m http.server 8000 # Node (si npm installé) npx http-server # Accès: http://localhost:8000

📚 Étape 4: Ajouter les ressources pédagogiques

Optionnel mais recommandé pour remplir la page Ressources.

  1. Crée les dossiers:
    assets/documents/ ├── semaine1/ ├── semaine2/ ├── semaine3/ ... └── semaine8/
  2. Ajoute tes fichiers PDF (ex: semaine1/01-maths.pdf)
  3. Mets à jour les liens dans education.html
    # De ceci: <a href="#" class="resource-link placeholder">À venir</a> # À ceci: <a href="assets/documents/semaine1/01-maths.pdf" download>Télécharger</a>

🎨 Étape 5: Personnalisation (optionnel)

Modifie les couleurs, polices, contenu selon tes préférences.

  • Texte/contenu: Édite directement les fichiers HTML
  • Couleurs: Modifie styles/base.css (variables :root)
  • Polices: Change --font-display et --font-sans
  • Plus d'infos: Voir CUSTOMIZATION.md

🚀 Étape 6: Déployer

Rends ton site accessible en ligne en quelques minutes.

  1. GitHub Pages (gratuit):
    • Crée un repo GitHub
    • Upload tous tes fichiers
    • Active Pages dans Settings
    • Accès: github.com/tonnom/repo
  2. Netlify (gratuit + plus de features):
    • Connecte ton repo GitHub
    • Déploiement automatique à chaque push
    • Custom domain possible
  3. Hébergeur classique (FTP):
    • Upload par FTP/SFTP
    • index.html à la racine

❓ Aide / Troubleshooting

La photo ne s'affiche pas?
→ Vérifie le chemin: assets/images/photo.jpg
→ Essaie .png au lieu de .jpg
→ Vérifiez la taille du fichier

Le site ne charge pas correctement?
→ Ouvre la console (F12) pour les erreurs
→ Utilise un serveur local (http://localhost)
→ Vide le cache navigateur (Ctrl+Shift+Delete)

Le thème ne change pas?
→ Vérifiez que scripts/app.js est chargé
→ Regardez la console pour erreurs
→ Vérifiez localStorage dans DevTools
